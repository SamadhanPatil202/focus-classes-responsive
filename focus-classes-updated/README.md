# Focus Classes Responsive 
Project link : https://focus-classes-responsive.vercel.app/

A full-stack educational platform developed for Focus Classes. This project is designed to provide a modern, responsive, and user-friendly website for an educational institute.

## Features

- Responsive design for all devices
- Modern user interface
- Student-friendly navigation
- Course information
- Faculty section
- Contact page
- Backend integration using Spring Boot
- REST API support

## Tech Stack

### Frontend
- React.js
- HTML5
- CSS3
- JavaScript
- Vite

### Backend
- Spring Boot
- Java
- REST API

### Database
- MySQL

## Purpose

This project was developed to create a professional online presence for Focus Classes, allowing students to access course information, institute details, and other educational resources through a responsive web application.

## Installation

### Frontend

```bash
npm install
npm run dev
```

### Backend

Import the Spring Boot project into your IDE and run the application.
